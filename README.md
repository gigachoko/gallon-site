# Gallon site (gallon.ge)

React + Vite პროექტი.

- `src/GallonSite.jsx` - საიტის მთავარი კომპონენტი
- `src/fuel-prices.json` - საწვავის ფასები და აღწერები (ფასის შესაცვლელად მხოლოდ ეს ფაილი შეცვალეთ)
- `src/assets/logo.png` - Gallon-ის ლოგო
- `vercel.json` - უსაფრთხოების ჰედერები (CSP და სხვ.)

Vercel-ის პარამეტრები: Framework Preset - Vite, Build Command - `npm run build`, Output Directory - `dist`.
